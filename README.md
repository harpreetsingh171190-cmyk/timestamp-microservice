# Timestamp Microservice

A simple backend project built with Node.js and Express as part of the freeCodeCamp Back End Development Certification.

## Features
- Accepts a date string or Unix timestamp.
- Returns a JSON object with the corresponding `unix` and `utc` date formats.
- Handles invalid dates and returns `{ error: "Invalid Date" }`.

## Technologies Used
- Node.js
- Express.js
- CORS
